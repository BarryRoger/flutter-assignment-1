# نظام المصادقة الطلابي المتكامل (Student Authentication System)

مشروع تطبيقي متكامل لنظام مصادقة طلابي مبني بالاعتماد التام على لغة **Dart** وإطار العمل **Flutter** بدون أي حزم خارجية (Pure Flutter & Dart).
يطبق المشروع النمط المعماري **MVC المعزز بنمط المستودع (Repository Pattern)** مع تطبيق صارم لكافة شروط التحقق من صحة النماذج (Form Validation).

---

## 🏛️ الهيكل المعماري للمشروع (Architectural Structure)

تم تنظيم الكود وفصل المسؤوليات بدقة داخل مجلد `lib/`:

```
lib/
├── models/                     # كائنات البيانات ونماذج الطلبات
│   ├── user_model.dart         # نموذج بيانات الطالب (UserModel)
│   └── auth_requests.dart      # كائنات الطلبات (Login, Register, Forgot, Reset) والنتائج (AuthResult)
│
├── repositories/               # طبقة المستودع (Repository Pattern)
│   ├── auth_repository.dart    # العقد التجريدي (Interface) لعمليات المصادقة
│   └── auth_repository_impl.dart # تطبيق المستودع بمحاكاة الشبكة وقاعدة بيانات تجريبية
│
├── controllers/                # إدارة الحالات ومنطق الأعمال (MVC Controller)
│   ├── auth_controller.dart    # متحكم المصادقة الموروث من ChangeNotifier الأصلي
│   └── auth_scope.dart         # موفر المتحكم عبر الشجرة باستخدام InheritedNotifier
│
├── utils/                      # دوال التحقق النقية
│   └── form_validators.dart    # دوال التحقق الثابتة لكافة الحقول (Form Validation)
│
├── views/                      # شاشات وواجهات المستخدم
│   ├── auth/                   # الشاشات الأربع الإجبارية
│   │   ├── login_page.dart     # 1. شاشة تسجيل الدخول
│   │   ├── register_page.dart  # 2. شاشة إنشاء الحساب الطلابي
│   │   ├── forgot_password_page.dart # 3. شاشة استعادة كلمة المرور
│   │   └── reset_password_page.dart  # 4. شاشة تعيين كلمة المرور الجديدة
│   ├── home/
│   │   └── student_dashboard_page.dart # لوحة تحكم الطالب بعد نجاح الدخول
│   └── widgets/
│       └── custom_text_field.dart # حقل إدخال موحد بتصميم أكاديمي أنيق
│
└── main.dart                   # نقطة انطلاق التطبيق مع دعم كامل للغة العربية (RTL)
```

## 📱 الشاشات ومواصفات التحقق المطبقة

### 1. شاشة تسجيل الدخول (`LoginPage`):
- **حقل المعرف أو البريد**: تحقق من عدم الفراغ وصحة الصيغة (≥ 5 خانات).
- **حقل كلمة المرور**: زر لاحقة لإظهار/إخفاء كلمة المرور (`Obscure Toggle`)، وتحقق (≥ 6 محارف).
- **صندوق "تذكرني" (`Remember Me`)**: يحفظ خيار التذكر داخل المتحكم.
- **رابط "نسيت كلمة المرور؟"**: ينقل إلى شاشة استعادة الحساب.
- **زر تسجيل الدخول**: فحص النموذج عبر `GlobalKey<FormState>`، استدعاء `controller.login()` مع مؤشر تحميل متجاوب (`CircularProgressIndicator`).
- **رابط إنشاء حساب**: ينقل مباشرة إلى شاشة `RegisterPage`.
- **بطاقة تعبئة تلقائية**: لتسهيل التجربة السريعة أثناء تقييم التكليف.

### 2. شاشة إنشاء الحساب (`RegisterPage`):
- **حقل الاسم الكامل**: تحقق من عدم الفراغ (≥ 3 محارف).
- **حقل الرقم الأكاديمي**: أرقام حصراً، يتراوح طوله بين 9 و 10 خانات.
- **حقل البريد الجامعي**: فحص دقيق عبر تعبير نمطي قياسي (`Email Regex`).
- **حقل كلمة المرور**: تطبيق سياسة أمان قوية (≥ 8 محارف + رقم واحد على الأقل + حرف كبير واحد على الأقل `A-Z`).
- **حقل تأكيد كلمة المرور**: مطابقة تامة 100% مع كلمة المرور المدخلة.
- **صندوق الموافقة على اللوائح والشروط الأكاديمية**: إلزامي لإتمام التسجيل، مع رسالة خطأ صريحة عند عدم تحديده، وإمكانية قراءة اللوائح بنافذة تفاعلية.
- **زر إنشاء الحساب**: يفحص النموذج والشروط، يستدعي `controller.register()`، وينقل تلقائياً لشاشة تسجيل الدخول مع رسالة نجاح.

### 3. شاشة استعادة كلمة المرور (`ForgotPasswordPage`):
- **بطاقة توجيهية أعلى الشاشة**: توضح آلية إرسال رمز التحقق واستعادة الحساب الأكاديمي.
- **حقل البريد أو الرقم الأكاديمي**: التحقق من عدم الفراغ وصحة المدخلات.
- **زر "إرسال رمز التحقق"**: يستدعي `controller.sendPasswordResetCode()`، يظهر شريط تنبيه أخضر (`SnackBar`) وينقل تلقائياً لشاشة `ResetPasswordPage`.
- **زر العودة لتسجيل الدخول**.

### 4. شاشة تعيين كلمة المرور الجديدة (`ResetPasswordPage`):
- **حقل رمز التحقق (OTP)**: مكون من 6 أرقام رقمية حصراً.
- **حقل كلمة المرور الجديدة**: مطابقة سياسة الأمان القوية.
- **حقل تأكيد كلمة المرور الجديدة**: مطابقة تامة مع الحقل السابق.
- **زر "تحديث كلمة المرور"**: يستدعي `controller.resetPassword()`، ويعرض نافذة تأكيد نجاح التحديث (`AlertDialog`) وتوجيه الطالب بضغطة زر لشاشة الدخول.
